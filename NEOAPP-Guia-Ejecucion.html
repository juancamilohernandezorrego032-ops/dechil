📚 Bienvenido a NEOAPP

Este proyecto es una aplicación fullstack moderna que combina:

Backend

Spring Boot

Java 17+

Base de datos H2

Frontend

React + Vite

Node.js 18+

Interfaz moderna

¿Qué es cada parte?

1 Backend (Spring Boot)

El servidor que proporciona las APIs REST. Maneja la lógica de negocio, valida datos y gestiona la base de datos.

2 Frontend (React + Vite)

La interfaz de usuario. Se conecta al backend para enviar y recibir datos. Vite es un empaquetador muy rápido.

3 Thunder Client

Una herramienta de pruebas (como Postman) integrada en VS Code para probar las APIs sin necesidad del frontend.

Esta guía te llevará paso a paso para ejecutar ambas partes, probar la API y resolver problemas comunes.

✅ Requisitos Previos

Antes de empezar, asegúrate de tener instalado lo siguiente:

1. Java 17 o Superior

Necesario para el backend. Spring Boot requiere Java 17 como mínimo.

🔍 Verificar si está instalado:

java -version

📥 Si no está instalado:

Descarga desde: https://www.oracle.com/java/technologies/downloads/

O usa un gestor de versiones como sdkman o jenv

2. Node.js (Versión 18 o Superior)

Necesario para el frontend. Incluye npm, el gestor de paquetes de JavaScript.

🔍 Verificar si está instalado:

node --version
npm --version

📥 Si no está instalado:

Descarga desde: https://nodejs.org/

Se recomienda descargar la versión LTS (Long Term Support)

3. Git (Opcional pero Recomendado)

Para clonar y versionear el proyecto.

Una vez verificado todo, estás listo para pasar a la siguiente sección. ¡Vamos! ⚡

🖥️ Ejecutar el Backend (Spring Boot)

El backend es el servidor que proporciona todas las APIs REST para que el frontend y Thunder Client se conecten.

Paso 1: Navegar a la Carpeta del Backend

Abre una terminal (PowerShell, CMD, Terminal de macOS o bash en Linux) y navega hasta la carpeta del backend:

cd neoapp1-develop-main/NEOAPP
Si estás en Windows con PowerShell, asegúrate de que el script de ejecución tenga permisos. Si te aparece un error, prueba con CMD en lugar de PowerShell.

Paso 2: Ejecutar el Backend

Usa Maven para compilar y ejecutar la aplicación. El comando depende de tu sistema operativo:

🪟 Windows (PowerShell / CMD)

./mvnw.cmd spring-boot:run

🍎 macOS / 🐧 Linux

./mvnw spring-boot:run

Paso 3: Esperar a que se Compile

Maven descargará todas las dependencias y compilará el proyecto. Esto puede tomar varios minutos la primera vez. Verás algo como:

[INFO] Scanning for projects...
[INFO] BUILD SUCCESS
[INFO] Started Application in X.XXX seconds

✅ Backend Ejecutándose

Una vez que veas el mensaje "Started", el backend está listo. Accede a:

📍 API Principal: http://localhost:8080/neoappapi/v1
📍 Consola H2: http://localhost:8080/h2-console

Credenciales para la Consola H2:

Campo Valor
JDBC URL jdbc:h2:mem:neoapp_bd
Usuario sa
Contraseña (dejar vacío)
¡El backend está corriendo! Ahora puedes ejecutar el frontend o probar la API con Thunder Client.

🛑 Detener el Backend

En la terminal, presiona Ctrl + C

⚛️ Ejecutar el Frontend (React + Vite)

El frontend es la interfaz de usuario. Se conectará automáticamente al backend que ejecutaste en la sección anterior.

Paso 1: Navegar a la Carpeta del Frontend

Abre una NUEVA terminal (sin cerrar la anterior donde corre el backend) y navega:

cd neoapp1-develop-main/NEOAPP/frontend
Es importante abrir una nueva terminal. Si cierras la anterior, detendrás el backend.

Paso 2: Instalar Dependencias

npm descargará todos los paquetes necesarios (React, Vite, etc.):

npm install
Esto solo es necesario la primera vez. Las siguientes veces puedes saltar directo al "Paso 3".

Paso 3: Iniciar el Servidor de Desarrollo

Vite compilará React y levantará un servidor de desarrollo muy rápido:

npm run dev

✅ Frontend Ejecutándose

Verás algo como:

  VITE v5.x.x  ready in 123 ms

  ➜  Local:   http://localhost:5173/
  ➜  press h + enter to show help
📍 Frontend: http://localhost:5173/
¡Abre tu navegador en esa URL! El frontend se conectará automáticamente al backend.

🛑 Detener el Frontend

En la terminal, presiona Ctrl + C

📊 Estado de Ejecución

Terminal 1 (Backend): Terminal 2 (Frontend): Backend Spring Boot ✓ Frontend React + Vite ✓ http://localhost:8080 http://localhost:5173

Ambas terminales deben estar activas simultáneamente

⚡ Importar Colección en Thunder Client

Thunder Client es una extensión de VS Code que permite probar APIs sin necesidad del frontend. Es como Postman, pero integrado en VS Code.

Paso 1: Instalar Thunder Client

Si aún no lo has hecho, instala la extensión en VS Code:

  1. Abre VS Code
  2. Ve a Extensiones (Ctrl + Shift + X)
  3. Busca "Thunder Client"
  4. Haz clic en "Instalar"

Paso 2: Abrir el Panel de Thunder Client

En la barra lateral izquierda de VS Code, haz clic en el ícono de Thunder Client (parece un rayo):

VS Code Sidebar ├── Explorer ├── Search ├── Source Control ├── Run and Debug ├── Extensions └── ⚡ Thunder Client ← Click aquí

Paso 3: Importar la Colección

Sigue estos pasos dentro de Thunder Client:

1 Haz clic en la pestaña "Collections"

2 Abre el menú (icono de 3 puntos ...)

Busca la opción de menú en la esquina superior derecha del panel de Thunder Client

3 Selecciona "Import"

Aparecerá un diálogo para seleccionar el archivo a importar

4 Ubica el archivo de colección

Navega a: thunder-tests/thunder-collection_neoapp.json

Este archivo se encuentra en la raíz del proyecto

5 Confirma la importación

La colección "NEOAPP API" aparecerá en tu lista de colecciones

✅ Colección Importada

Ahora verás todas las pruebas disponibles organizadas:

Collections └── NEOAPP API ├── Autenticación ├── Usuarios ├── Productos └── Más endpoints...

🧪 Pruebas Disponibles

📝 Crear Usuario (Dato Dinámico)

Esta solicitud genera datos aleatorios cada vez que la envías:

{
  "documento": "{{#random_number}}",
  "correo": "usuario-{{#random_number}}@neoapp.com",
  "nombre": "Usuario Prueba",
  "password": "password123"
}
Usa esta para crear múltiples usuarios sin errores de duplicidad. Los datos se regeneran automáticamente cada envío.

❌ Crear Usuario (Dato Fijo - Para Probar Error)

Esta solicitud usa datos fijos (siempre los mismos):

{
  "documento": "1234567890",
  "correo": "admin@neoapp.com",
  "nombre": "Administrador",
  "password": "admin123"
}
La primera vez funcionará. La segunda vez generará un error 400 Bad Request (violación de clave única). Esto es intencional para validar la respuesta de error.

🚀 Enviar una Solicitud

  1. Selecciona una solicitud de la colección
  2. Haz clic en el botón "Send" (o presiona Ctrl + Enter)
  3. Verás la respuesta en el panel derecho
¡Listo! Ahora puedes probar todos los endpoints de la API sin necesidad de usar el frontend.

🔧 Solución de Problemas Comunes

❌ Error: "Port 8080 was already in use"

Significa que otro proceso está usando el puerto 8080 del backend.

Solución Rápida (Windows PowerShell):

Ejecuta esta única línea para terminar el proceso:

Stop-Process -Id (Get-NetTCPConnection -LocalPort 8080).OwningProcess -Force

Solución Alternativa: Cambiar el Puerto

Si prefieres que la aplicación corra en otro puerto permanentemente (ej: 8081):

1 Abre el archivo de configuración

neoapp1-develop-main/NEOAPP/src/main/resources/application.properties

2 Agrega esta línea al final:

server.port=8081

3 Guarda el archivo

4 Reinicia el backend

Detén (Ctrl + C) y vuelve a ejecutar con ./mvnw.cmd spring-boot:run

Si cambias el puerto a 8081, recuerda actualizar:
  • La URL base en Thunder Client: http://localhost:8081
  • La URL en el frontend (si está configurada manualmente)

❌ Error: "npm: command not found"

Node.js no está instalado o no está en el PATH del sistema.

Solución:

  1. Verifica que Node.js esté instalado: node --version
  2. Si no aparece, descárgalo desde https://nodejs.org/
  3. Reinicia tu terminal después de la instalación

❌ Error: "java: command not found"

Java no está instalado o no está en el PATH del sistema.

Solución:

  1. Verifica que Java esté instalado: java -version
  2. Si no aparece, descárgalo desde https://www.oracle.com/java/technologies/downloads/
  3. Reinicia tu terminal después de la instalación

❌ Error: "BUILD FAILURE" en Maven

Puede deberse a problemas de dependencias o configuración.

Soluciones a Intentar:

  1. Limpia el caché de Maven: 
    ./mvnw clean
  2. Intenta nuevamente: 
    ./mvnw spring-boot:run
  3. Si persiste, verifica la consola para más detalles del error

❌ El Frontend no se Conecta al Backend

El frontend envía solicitudes HTTP al backend, pero no obtiene respuesta.

Verificaciones:

1 Asegúrate de que el backend está corriendo

Abre en tu navegador: http://localhost:8080/neoappapi/v1

Deberías ver una respuesta (no un error de conexión)

2 Verifica la consola del navegador

Presiona F12 → pestaña "Console" → busca errores de CORS o conexión

3 Recarga la página del frontend

Presiona Ctrl + Shift + R (recarga completa)

4 Si cambió el puerto del backend

Actualiza la configuración en el frontend para que apunte al puerto correcto

❌ "Port 5173 was already in use" (Frontend)

El puerto del frontend ya está ocupado.

Solución en Windows (PowerShell):

Stop-Process -Id (Get-NetTCPConnection -LocalPort 5173).OwningProcess -Force

Solución Alternativa: Cambiar Puerto

Edita vite.config.js en la carpeta del frontend:

export default {
  server: {
    port: 5174
  }
}
¿Aún tienes problemas? Revisa la consola para mensajes de error específicos. Usualmente ahí encontrarás la raíz del problema.
